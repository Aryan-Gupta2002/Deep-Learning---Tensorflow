# 🧠 Deep Learning with TensorFlow

This repository contains a collection of hands-on **Deep Learning experiments and implementations** using **TensorFlow and Neural Networks**.

It covers core concepts such as classification, regression, RNNs, CNN fine-tuning, preprocessing, and image segmentation through practical notebooks.

---

## 🚀 What You’ll Learn

* Fundamentals of TensorFlow
* Neural Networks for:

  * Regression
  * Binary Classification
* Model training & evaluation techniques
* Data preprocessing (Normalization, MinMax Scaling)
* CNN fine-tuning
* Recurrent Neural Networks (RNNs)
* Image Segmentation basics
* Saving & loading models

---

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/aryan-gupta2002/Deep-Learning---Tensorflow.git
cd Deep-Learning---Tensorflow
```

2. Install dependencies:

```bash
pip install tensorflow numpy matplotlib jupyter
```

3. Start Jupyter Notebook:

```bash
jupyter notebook
```

4. Open any `.ipynb` file and run cells step-by-step
